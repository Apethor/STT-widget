license. The package copies effects to its private `soundboard` folder; it never
changes a person's original/custom files or recording exports.

The previous Nintendo excerpts `mario-pipe.wav` and `mario-star.wav` are no
longer bundled or present in this source tree. Their button IDs remain as
compatibility identifiers. Catalog migration selects the new files while
preserving any existing installed copies and explicitly edited names.

The legacy filename `laughter.mp3` is still understood by migration, which
selects the new filename while leaving any old installed copy intact.
The old recording is not embedded or required to build the current application.
